# blookblu-front — فرانت بلوک (نسخهٔ نمایشی)

اپ موبایل‌محور **بلوک** برای شش نقش شخصی (کارگر، متخصص، مهندس، پیمانکار، شرکت ساختمانی، کارفرما).
فعلاً با **دادهٔ نمایشی** کار می‌کند و هنوز به بک‌اند ([blookblu](https://github.com/mjd7lord-hue/blookblu)) وصل نیست.

**لینک تست:** https://mjd7lord-hue.github.io/blookblu-front/

- یک فایل: `index.html` (HTML/CSS/JS بدون وابستگی؛ فقط فونت وزیرمتن از Google Fonts)
- راست‌به‌چپ، حالت تیره/روشن، مناسب گوشی

## فعال کردن لینک تست (یک بار)
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
چند دقیقه بعد لینک بالا کار می‌کند.
